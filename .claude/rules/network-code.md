# 网络代码规范

- 服务器对所有游戏性关键状态具有权威性 —— 绝不信任客户端
- 所有网络消息必须进行版本控制，以实现前向/后向兼容
- 客户端本地预测，与服务器进行校正 —— 为预测错误实现回滚
- 妥善处理断开连接、重连和主机迁移
- 对所有网络日志进行速率限制，防止日志洪水
- 所有网络化的值必须指定复制策略：可靠/不可靠、频率、插值方式
- 带宽预算：定义并追踪每条消息类型的带宽使用量
- 安全：验证所有传入数据包的大小和字段范围

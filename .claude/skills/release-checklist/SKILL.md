> **仅显式调用**：此 Skill 应仅在用户通过 `/release-checklist` 明确请求时运行。不要基于上下文匹配自动调用。

## 阶段 1：解析参数

读取目标平台的参数（`pc`、`console`、`mobile` 或 `all`）。如果未指定平台，默认为 `all`。

---

## 阶段 2：加载项目上下文

- 读取 `CLAUDE.md` 了解项目上下文、版本信息和目标平台。
- 从 `production/milestones/` 中读取当前里程碑，了解此版本应包含哪些功能和内容。

---

## 阶段 3：扫描代码库

扫描待解决的问题：

- 统计 `TODO` 注释数量
- 统计 `FIXME` 注释数量
- 统计 `HACK` 注释数量
- 注意它们的位置和严重性

检查测试输出目录或 CI 日志中的测试结果（如果可用）。

---

## 阶段 4：生成发布清单

```markdown
## 发布清单：[版本] -- [平台]
生成时间：[日期]

### 代码库健康度
- TODO 数量：[N]（[如果很多，列出前 5 个]）
- FIXME 数量：[N]（[列出全部——这些是潜在的阻塞项]）
- HACK 数量：[N]（[列出全部——这些需要审查]）

### 构建验证
- [ ] 在所有目标平台上都能干净构建成功
- [ ] 没有编译器警告（零警告策略）
- [ ] 所有资源均已包含且正确加载
- [ ] 构建大小在预算范围内（[目标大小]）
- [ ] 构建版本号已正确设置（[版本]）
- [ ] 构建可从标记的提交复现

### 质量门禁
- [ ] 零个 S1（严重）Bug
- [ ] 零个 S2（主要）Bug——或有经制作人批准的文档化例外
- [ ] 所有关键路径功能已测试并由 QA 签署确认
- [ ] 性能在预算范围内：
  - [ ] 在最低规格硬件上达到目标帧率
  - [ ] 内存使用在预算范围内
  - [ ] 加载时间在预算范围内
  - [ ] 长时间游戏过程中没有内存泄漏
- [ ] 相比上一个构建没有回归
- [ ] 浸泡测试通过（4+ 小时连续游戏）

### 内容完整
- [ ] 所有占位资源已替换为最终版本
- [ ] 所有内容文件中的 TODO/FIXME 已解决或已记录
- [ ] 所有面向玩家的文本已校对
- [ ] 所有文本已做好本地化准备（没有硬编码字符串）
- [ ] 音频混音已完成并获得批准
- [ ] 制作人员名单完整且准确
```

根据参数添加特定平台的部分：

**`pc` 平台：**
```markdown
### 平台要求：PC
- [ ] 最低和推荐配置已验证并记录
- [ ] 键盘+鼠标控制完全可用
- [ ] 控制器支持已测试（Xbox、PlayStation、通用）
- [ ] 分辨率缩放已测试（1080p、1440p、4K、超宽屏）
- [ ] 窗口模式、无边框和全屏模式正常工作
- [ ] 图形设置保存和加载正确
- [ ] Steam/Epic/GOG SDK 集成并已测试
- [ ] 成就功能正常
- [ ] 云存档功能正常
- [ ] Steam Deck 兼容性已验证（如果以此为目标）
```

**`console` 平台：**
```markdown
### 平台要求：主机
- [ ] TRC/TCR/Lotcheck 要求清单已完成
- [ ] 特定平台的手柄按键提示显示正确
- [ ] 暂停/恢复正常工作
- [ ] 用户切换正确处理
- [ ] 网络连接丢失已优雅处理
- [ ] 存储空间已满的场景已处理
- [ ] 家长控制已遵守
- [ ] 特定平台的成就/奖杯集成已测试
- [ ] 第一方认证提交已准备好
```

**`mobile` 平台：**
```markdown
### 平台要求：移动端
- [ ] 应用商店指南合规性已验证
- [ ] 所有必需的设备权限已合理说明并记录
- [ ] 隐私政策已链接且准确
- [ ] 数据安全/营养标签已完成
- [ ] 触摸控制在多种屏幕尺寸上已测试
- [ ] 电池使用量在可接受范围内
- [ ] 后台行为正确（暂停、恢复、终止）
- [ ] 推送通知权限正确处理
- [ ] 应用内购买流程已测试（如适用）
- [ ] 应用大小在商店限制内
```

**商店和发布部分（所有平台）：**
```markdown
### 商店/分发
- [ ] 商店页面元数据完整并已校对
  - [ ] 简短描述
  - [ ] 详细描述
  - [ ] 功能列表
  - [ ] 系统要求（PC）
- [ ] 截图是最新的且符合各平台分辨率要求
- [ ] 宣传片是最新的
- [ ] 关键视觉图和封面图片是最新的
- [ ] 年龄分级已获取并配置：
  - [ ] ESRB
  - [ ] PEGI
  - [ ] 其他按需的地区分级
- [ ] 法律声明、EULA 和隐私政策已到位
- [ ] 第三方许可署名完整
- [ ] 所有地区的定价已配置

### 发布就绪状态
- [ ] 分析/遥测已验证并接收数据
- [ ] 崩溃报告已配置且仪表板可访问
- [ ] 首日补丁已准备并测试（如需要）
- [ ] 发布后前 72 小时值班团队排班已安排
- [ ] 社区发布公告已起草
- [ ] 媒体/主播评测密钥已准备好分发
- [ ] 支持团队已了解已知问题和 FAQ
- [ ] 回滚计划已记录（如果发布后发现严重问题）

### 通过 / 不通过：[就绪 / 未就绪]

**理由：**
[就绪评估摘要。列出必须在发布前解决的任何阻塞项。如果未就绪，列出需要解决的具体项以及解决所需的时间估算。]

**需要签署确认：**
- [ ] QA 负责人
- [ ] 技术总监
- [ ] 制作人
- [ ] 创意总监
```

---

## 阶段 5：保存清单

向用户呈现清单：清单项总数、已知阻塞项数量（FIXME/HACK 数量、已知 Bug）。

询问："我可以将此写入 `production/releases/release-checklist-[version].md` 吗？"

如果同意，写入文件，必要时创建目录。

---

## 阶段 6：后续步骤

- 运行 `/gate-check` 以在继续发布之前获得正式阶段门禁裁决。
- 通过 `/team-release` 协调最终签署确认。

> **仅显式调用**：此 Skill 应仅在用户通过 `/launch-checklist` 明确请求时运行。不要基于上下文匹配自动调用。

## 阶段 1：解析参数

读取参数以获取发布日期或 `dry-run` 模式。Dry-run 模式生成清单但不创建签署条目或写入文件。

---

## 阶段 2：收集项目上下文

- 读取 `CLAUDE.md` 了解技术栈、目标平台和团队结构
- 读取 `production/milestones/` 中最新的里程碑
- 读取 `production/releases/` 中任何现有的发布清单
- 读取 `design/live-ops/content-calendar.md`（如果存在）

---

## 阶段 3：扫描代码库健康状况

- 统计 `TODO`、`FIXME`、`HACK` 注释及其位置
- 检查生产代码中是否有任何 `console.log`、`print()` 或调试输出残留
- 检查占位资源（搜索 `placeholder`、`temp_`、`WIP_`）
- 检查硬编码的测试/开发值（localhost、测试凭据、调试标志）

---

## 阶段 4：生成发布清单

```markdown
# 发布清单：[游戏标题]
目标发布日期：[日期 或 DRY RUN]
生成时间：[日期]

---

## 1. 代码就绪状态

### 构建健康状况
- [ ] 在所有目标平台上都能干净构建
- [ ] 零编译器警告
- [ ] 所有单元测试通过
- [ ] 所有集成测试通过
- [ ] 性能基准在目标范围内
- [ ] 无内存泄漏（通过长时间浸泡测试验证）
- [ ] 构建大小在平台限制内
- [ ] 构建版本正确设置并在源代码管理中打标签

### 代码质量
- [ ] TODO 数量：[N]（发布要求为零，或有文档化的例外）
- [ ] FIXME 数量：[N]（要求为零）
- [ ] HACK 数量：[N]（每个必须有文档化的理由）
- [ ] 生产代码中没有调试输出
- [ ] 没有硬编码的开发/测试值
- [ ] 所有功能标志设置为生产值
- [ ] 错误处理覆盖所有关键路径
- [ ] 崩溃报告已集成并已验证

### 安全
- [ ] 源代码中没有暴露的 API 密钥或凭据
- [ ] 存档数据已加密
- [ ] 网络通信已保护（TLS/DTLS）
- [ ] 反作弊措施已激活（如果有多人游戏）
- [ ] 所有服务器端点的输入已验证（如果有多人游戏）
- [ ] 隐私政策合规性已验证

---

## 2. 内容就绪状态

### 资源
- [ ] 所有占位图已替换为最终资源
- [ ] 所有占位音频已替换为最终音频
- [ ] 音频混音已最终确认并经音频总监批准
- [ ] 所有视觉特效已打磨并验证性能
- [ ] 没有缺失或损坏的资源引用
- [ ] 资源命名规范已强制执行

### 文本和本地化
- [ ] 所有面向玩家的文本已校对
- [ ] 没有硬编码字符串（全部已外置以进行本地化）
- [ ] 所有支持的语言已翻译并已验证
- [ ] 文本在所有语言中适合 UI（文本适配检查完成）
- [ ] 字体覆盖已验证支持所有语言
- [ ] 制作人员名单完整、准确且最新

### 游戏内容
- [ ] 所有关卡/地图从头到尾可玩
- [ ] 教程流程已完成并与新玩家测试
- [ ] 所有成就/奖杯已实现并已测试
- [ ] 保存/加载在所有游戏状态下正常工作
- [ ] 难度设置已平衡并已测试
- [ ] 结局/制作人员名单序列已完成

---

## 3. 质量保证

### 测试
- [ ] 完整回归测试套件已通过
- [ ] 零个 S1（严重）Bug 未关闭
- [ ] 零个 S2（主要）Bug 未关闭（或有文档化的例外）
- [ ] 浸泡测试已通过（8+ 小时连续游戏）
- [ ] 多人压力测试已通过（如适用）
- [ ] 所有关键用户路径在每个平台上已测试
- [ ] 边界情况已测试（存储满、无网络、暂停/恢复）

### 平台认证
- [ ] PC：Steam/Epic/GOG SDK 要求已满足
- [ ] 主机：TRC/TCR/Lotcheck 提交已准备好
- [ ] 移动端：App Store/Play Store 指南已合规
- [ ] 无障碍：最低标准已满足（键位重映射、文本缩放、色盲）
- [ ] 年龄分级已获得（ESRB、PEGI、各地区）

### 性能
- [ ] 在最低规格硬件上达到目标帧率
- [ ] 在所有平台上加载时间在预算内
- [ ] 在所有平台上内存使用在预算内
- [ ] 网络带宽在目标内（如果有多人游戏）
- [ ] 关键游戏时刻没有帧卡顿

---

## 4. 商店和分发

### 商店页面
- [ ] 商店页面文案已最终确认并已校对
- [ ] 截图是最新的且每平台分辨率正确
- [ ] 宣传片是最新的并已批准
- [ ] 关键艺术图和胶囊图片已最终确认
- [ ] 系统要求准确（PC）
- [ ] 所有地区定价已配置
- [ ] 预购/愿望单活动已激活（如适用）

### 法务
- [ ] EULA 已最终确认并经法务批准
- [ ] 隐私政策已发布并链接
- [ ] 第三方许可署名完整
- [ ] 音乐/音频授权已验证
- [ ] 商标/IP 审查已确认
- [ ] GDPR/CCPA 合规性已验证（数据收集、同意、删除）

---

## 5. 基础设施

### 服务器（如果有多人/在线）
- [ ] 生产服务器已配置并负载测试
- [ ] 自动伸缩已配置并已测试
- [ ] 数据库备份已配置
- [ ] CDN 已配置用于内容分发
- [ ] DDoS 防护已激活
- [ ] 监控和告警已配置

### 分析和监控
- [ ] 分析管道已验证并接收数据
- [ ] 崩溃报告已激活且仪表板可访问
- [ ] 服务器监控仪表板已上线
- [ ] 关键指标跟踪中：DAU、会话时长、留存率、崩溃率
- [ ] 关键阈值的告警已配置

---

## 6. 社区和市场营销

### 社区就绪
- [ ] 社区准则已发布
- [ ] 管理团队已了解情况且工具已就绪
- [ ] Discord/论坛/社交渠道已搭建
- [ ] FAQ 和已知问题页面已准备好
- [ ] 支持邮箱/工单系统已激活

### 市场营销
- [ ] 发布宣传片已发布
- [ ] 媒体/主播评测密钥已分发
- [ ] 社交媒体发布帖子已排期
- [ ] 发布日博客文章/开发者更新已起草
- [ ] 发布版本的补丁说明已发布

---

## 7. 运营

### 团队就绪
- [ ] 发布后前 72 小时值班排班已设置
- [ ] 事件响应手册已由团队审查
- [ ] 回滚计划已记录并已测试
- [ ] 热修复管道已测试（能在 4 小时内发布紧急修复）
- [ ] 发布问题的沟通计划已就绪（谁发布、哪里发布、多快发布）

### 首日计划
- [ ] 首日补丁已准备（如需要）
- [ ] 服务器解锁/上线流程已记录
- [ ] 发布监控仪表板已被所有负责人收藏
- [ ] 发布日作战室/频道已建立

---

## 通过 / 不通过决策

**总体状态**：[就绪 / 未就绪 / 有条件]

### 阻塞项
[列出任何必须在发布前解决的问题]

### 有条件项
[列出有文档化变通方案或已接受风险的项目]

### 需要的签署确认
- [ ] 创意总监 — 内容和体验质量
- [ ] 技术总监 — 技术健康和稳定性
- [ ] QA 负责人 — 质量和测试覆盖率
- [ ] 制作人 — 排期和整体就绪
- [ ] 发布经理 — 构建和部署就绪
```

---

## 阶段 5：保存清单

向用户呈现完成的清单和摘要（总项目数、阻塞项目数、有条件项目数、有不完整部分的部门）。

如果不是 dry-run 模式，询问："我可以将此写入 `production/releases/launch-checklist-[date].md` 吗？"

如果同意，写入文件，必要时创建目录。

---

## 阶段 6：后续步骤

- 运行 `/gate-check` 以在发布前获得正式的通过/疑虑/不通过裁决。
- 通过 `/team-release` 协调签署确认。
